**Responsive News Website Using HTML, CSS & JavaScript**
_Key Responsibilities:_
Designed and developed a dynamic news website interface using HTML for structure, CSS for styling, and JavaScript for logic.

Integrated NewsData.io API to fetch and display live news based on user queries or category selections (e.g., IPL, Finance, Politics).

Implemented a search functionality and interactive navigation with active state management using JavaScript.

Created reusable card templates via <template> tag for cleaner DOM manipulation.

Added a footer section with links to social platforms (LinkedIn, Instagram).

Focused on clean UI/UX, responsive layout, and accessibility.

_Responsiveness and Effectiveness:_
HTML: Used semantic elements (<nav>, <main>, <footer>, <template>) and a structured layout to ensure accessibility and clean markup.

CSS: Utilized Flexbox (.flex class, .container) to make the layout responsive across devices (desktops, tablets, mobiles). Designed adaptive elements such as navbars, card grids, and input fields.

JavaScript: Made the app interactive and dynamic:

Fetches live news based on categories and search.

Highlights active navigation state.

Efficiently renders multiple news cards using DOM cloning.

Reloads and resets UI dynamically.
